# Sistema de anonimización

## Clasificación

- **Público:** información ya publicada y autorizada.
- **Real anonimizado:** trabajo real sin cliente, personas, identificadores ni reglas propietarias.
- **Conceptual:** propuesta creada para demostrar una hipótesis; nunca presentarla como cliente real.
- **Académico:** ejercicio de formación identificado como tal.
- **Restringido:** no publicar.

## Antes de publicar una evidencia

1. Confirmar autoría, rol y permiso de uso.
2. Eliminar nombres internos, IDs, emails, teléfonos y ubicaciones precisas.
3. Reemplazar datos por ejemplos ficticios claramente consistentes.
4. Revisar metadatos del archivo y capas ocultas.
5. Comprobar que no revela reglas propietarias ni información competitiva.
6. Registrar fuente y aprobación sin almacenar datos sensibles.

Las capturas del registrador y de cPanel no son activos del portafolio porque contienen datos personales y de infraestructura.
