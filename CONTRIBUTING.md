# Contribuir

1. Partir desde `main` actualizado.
2. Crear una rama `feature/*`, `fix/*`, `docs/*`, `test/*`, `perf/*` o `chore/*`.
3. Mantener cambios pequeños y verificables.
4. Ejecutar lint, typecheck, tests y generación estática.
5. Revisar contenido, accesibilidad, responsive y confidencialidad.
6. Usar commits como `feat:`, `fix:`, `docs:`, `test:`, `perf:` o `chore:`.

No incluir secretos ni información profesional no verificada.
